# ADR-0003: REST API с простым HTML/CSS/JS

## Контекст и постановка задачи

Как реализовать интерактивную Kanban-доску без сложного фронтенд-стека?

## Драйверы решения

- REQ-FUNC-002/004
- REQ-DIST-002
- Ограниченная команда

## Рассмотренные варианты

- REST + HTML/CSS/JS
- React SPA + REST
- Thymeleaf без JS

## Итог решения

Выбран вариант **«REST + HTML/CSS/JS»**, поскольку обеспечивает изменение колонок без полной перезагрузки и не требует сборки SPA.

### Последствия

- Хорошо: простая разработка UI.
- Ограничение: часть DOM-логики пишется вручную.

### Подтверждение

Проверить проектное решение в код-ревью и интеграционных тестах; результаты фиксировать в Pull Request.

## Плюсы и минусы вариантов

### REST + HTML/CSS/JS

- Плюс: малое время реализации и совместимость с текущим SRS.
- Минус: есть ограничения, перечисленные в последствиях решения.

### React SPA + REST

- Плюс: реалистичная альтернативная архитектура.
- Минус: высокая дополнительная стоимость разработки и сопровождения для учебного проекта.

### Thymeleaf без JS

- Плюс: реалистичная альтернативная архитектура.
- Минус: высокая дополнительная стоимость разработки и сопровождения для учебного проекта.
