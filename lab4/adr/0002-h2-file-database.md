# ADR-0002: Постоянное хранение в файловой H2

## Контекст и постановка задачи

Как сохранить задачи после перезапуска и избежать дополнительного сервера БД?

## Драйверы решения

- REQ-FUNC-010
- REQ-INST-001/002
- Локальная учебная демонстрация

## Рассмотренные варианты

- H2 в файловом режиме
- PostgreSQL
- Хранение JSON на диске

## Итог решения

Выбран вариант **«H2 в файловом режиме»**, поскольку не требует отдельного сервера и поддерживает транзакции и JPA.

### Последствия

- Хорошо: запуск без отдельного СУБД.
- Ограничение: для многопользовательского production следует перейти на PostgreSQL.

### Подтверждение

Проверить проектное решение в код-ревью и интеграционных тестах; результаты фиксировать в Pull Request.

## Плюсы и минусы вариантов

### H2 в файловом режиме

- Плюс: малое время реализации и совместимость с текущим SRS.
- Минус: есть ограничения, перечисленные в последствиях решения.

### PostgreSQL

- Плюс: реалистичная альтернативная архитектура.
- Минус: высокая дополнительная стоимость разработки и сопровождения для учебного проекта.

### Хранение JSON на диске

- Плюс: реалистичная альтернативная архитектура.
- Минус: высокая дополнительная стоимость разработки и сопровождения для учебного проекта.
