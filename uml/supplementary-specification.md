# Дополнительные спецификации TaskFlow

## Бизнес-правила

| ID | Правило | SRS |
|---|---|---|
| BR-01 | Новая задача создаётся со статусом TODO | REQ-FUNC-001 |
| BR-02 | Статусы ограничены TODO, IN_PROGRESS, DONE | REQ-FUNC-004 |
| BR-03 | Приоритеты ограничены LOW, MEDIUM, HIGH | REQ-FUNC-006 |
| BR-04 | Пустое название отклоняется сервером | REQ-FUNC-009 |
| BR-05 | Удаление возможно только после подтверждения | REQ-FUNC-005 |
| BR-06 | Повторение допускает NONE, DAILY, WEEKLY | REQ-FUNC-013 |
| BR-07 | Для DAILY/WEEKLY обязательна дата dueDate | REQ-FUNC-013 |
| BR-08 | Повтор создаётся при переходе в DONE: +1 день для DAILY, +7 для WEEKLY | REQ-FUNC-013 |
| BR-09 | Повторное завершение не должно порождать дубли | REQ-FUNC-013 |
| BR-10 | Новая повторная задача наследует название, описание, приоритет и получает TODO | REQ-FUNC-013 |
| BR-11 | CSV содержит id,title,description,priority,status,dueDate и кодировку UTF-8 | REQ-FUNC-011 |
| BR-12 | При сбое сохранения не показывать ложный успех | REQ-REL-001 |

## Общие требования (FURPS+)

- Функциональность: операции над задачами и повторение по REQ-FUNC-001…011, 013; сортировка REQ-FUNC-012 отложена.
- Удобство: три колонки, обратная связь об ошибках, подтверждение удаления, пустые колонки (SRS 3.1.1).
- Надёжность: не подтверждать неуспешную запись; контролировать недоступность хранилища (REQ-REL-001, 002).
- Производительность: доска до 500 задач и CRUD отвечают не более 2 секунд в 95% запросов (REQ-PERF-001, 002).
- Безопасность: серверная валидация, запрет выполнения введённого SQL/кода, HTTPS в рабочем развёртывании, отсутствие секретов в ошибках (REQ-SEC-001…004).
- Поддержка: Java/Spring Boot, разделение UI/сервиса/доступа к данным, конфигурация окружения (REQ-MAINT-001, REQ-INST-002).
- Ограничения: без ролей, календаря, чата, внешних интеграций; без фонового планировщика повторов.

## Проектные уточнения

Атомарная операция изменения статуса и создания следующего экземпляра, а также технический маркер уникальности повтора являются предложенными механизмами обеспечения REQ-FUNC-013 и REQ-REL-001. SRS не задаёт конкретный формат маркера или схему БД; эти детали подлежат подтверждению при реализации.
