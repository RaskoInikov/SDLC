# Глоссарий TaskFlow

Основание: srs-taskflow.md (v0.2 от 28.10.2026). Указанные классы — проектные имена, а не подтверждение реализации.

| № | Термин | Определение | Соответствие модели |
|---|---|---|---|
| 1 | Задача | Единица работы с названием, описанием, приоритетом, сроком и статусом | `Task` |
| 2 | Доска Kanban | Три колонки, отображающие состояния задач | `TaskBoard` |
| 3 | К выполнению | Начальное состояние задачи | `TaskStatus.TODO` |
| 4 | В работе | Состояние выполняемой задачи | `TaskStatus.IN_PROGRESS` |
| 5 | Готово | Состояние завершённой задачи | `TaskStatus.DONE` |
| 6 | Статус | Текущее положение задачи на Kanban-доске | `Task.status` |
| 7 | Приоритет | Важность задачи: низкий, средний, высокий | `Priority` |
| 8 | Низкий | Низший приоритет | `Priority.LOW` |
| 9 | Средний | Средний приоритет | `Priority.MEDIUM` |
| 10 | Высокий | Наивысший приоритет | `Priority.HIGH` |
| 11 | Срок | Необязательная дата выполнения | `Task.dueDate` |
| 12 | Создание задачи | Добавление новой задачи в колонку «К выполнению» | `TaskService.create` |
| 13 | Редактирование | Изменение названия, описания, приоритета, срока | `TaskService.update` |
| 14 | Удаление | Удаление задачи после подтверждения | `TaskService.delete` |
| 15 | Поиск | Отбор задач по вхождению текста в название или описание | `TaskService.search` |
| 16 | Фильтрация | Ограничение списка по статусу и приоритету | `TaskService.filter` |
| 17 | CSV | Текстовый табличный формат экспорта в UTF-8 | `CsvExporter` |
| 18 | Экспорт CSV | Выгрузка задач с определёнными шестью колонками | `CsvExporter.export` |
| 19 | Повторяющаяся задача | Задача, создающая следующую при завершении | `Task.recurrenceRule` |
| 20 | Без повторения | Правило отсутствия новой задачи после завершения | `RecurrenceRule.NONE` |
| 21 | Ежедневно | Повторение со сдвигом срока на один день | `RecurrenceRule.DAILY` |
| 22 | Еженедельно | Повторение со сдвигом срока на семь дней | `RecurrenceRule.WEEKLY` |
| 23 | Экземпляр повтора | Следующая задача после завершения текущей | `Task.nextOccurrence` |
| 24 | Защита от дублирования | Повторное завершение не создаёт новую задачу | `CompletionGuard` |
| 25 | Постоянное хранилище | База данных, сохраняющая задачи после перезапуска | `TaskRepository` |
| 26 | HTTP API | Интерфейс взаимодействия клиента и Java-сервера | `TaskController` |
| 27 | Валидация | Проверка данных на сервере перед сохранением | `TaskValidator` |
| 28 | Транзакция | Атомарное изменение статуса и создание повтора | `TaskService.complete` |
| 29 | Прецедент | Взаимодействие актёра и системы с результатом | `UML use case` |
| 30 | Актёр | Внешняя роль пользователя | `UML actor` |
| 31 | Дорожка | Раздел активности по исполнителю | `UML activity partition` |
| 32 | Линия жизни | Временное существование участника обмена сообщениями | `UML lifeline` |
| 33 | Сторожевое условие | Условие перехода в квадратных скобках | `UML guard` |
| 34 | Включение include | Обязательное общее поведение | `UML include` |
| 35 | Расширение extend | Поведение, добавляемое при выполнении условия | `UML extend` |
